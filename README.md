# TinyMeter

## What is it?
A simple, efficient lightmeter to be used with manual film cameras

### But there are other lightmeters available for android, why create a new one?
Yes, there are alternatives, but many have essential features locked behind paywalls, poor efficiency or simply unintuitive UI's to use (just my personal take).
TinyMeter is designed to be efficient and most importantly quick to use.

## Features
* Aperture and Shutter priority modes as well as a manual mode (currently WIP, doesn't seem to be accurate)
* Spot and average metering (NOTE: Spot metering is not reliable yet!)

## Future features
* At least a persistent widget that can be activated so that the user does not need to unlock the phone (say, in cold winter weather) to see an average metering of the scene.
